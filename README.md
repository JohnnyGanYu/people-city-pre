# 人民城市考卷：上海 vs 纽约

一份大学课堂展示的全部资料：讲稿、PPT、数据核实记录和截图。我们把"人民城市"当成一张考卷，让上海和纽约用同一套分项指标作答，回答一个问题：纽约能不能叫人民城市？

每个数字都附官方出处，算法和口径公开，欢迎核对和指错。

## 结论

| | 题 | 胜方 | 程度 | 主要依据 |
|---|---|---|---|---|
| 基本项 | 住 | 上海 | 明显 | 自有住房率：上海 59%（2020），纽约市 32%（2023） |
| | 吃 | 纽约 | 稍胜 | 人均吃的花销：纽约州约 6.3 万元，上海 1.35 万元；餐饮价格随工资走，实际差距小于账面 |
| | 穿 | 纽约 | 压倒性 | 人均衣着支出：纽约州接近上海的 7 倍 |
| | 行 | 上海 | 压倒性 | 票价按两城收入差距折算后约为纽约的一半；交通支出占消费的比例更低 |
| 加分项 | 医疗 | 上海 | 明显 | 期望寿命持平；婴儿死亡率上海 2.34‰、纽约 4.2‰；孕产妇死亡率相差 10 倍以上 |
| | 治安 | 上海 | 压倒性 | 每 10 万人杀人案：上海 0.19 起，纽约 3.6 起 |
| | 教育 | 打平 | — | 义务教育生师比：上海 12.5，纽约 13.2 |
| | 文化 | 纽约 | 明显 | 公共图书馆网络和财政托底的免费文化项目 |
| 单列 | 对待底层 | 上海 | 压倒性 | 纽约无家可归 12.6 万人（2025 一夜点数） |

各题差距大小不一，所以不加总分。我们的回答是：纽约在吃穿、公共文化和数据公开上答得好，但最底层的人没有被托住，这张卷子还不算及格；上海答得更完整，数据公开这一题还得补。比较只限于两座城市，不扩大成两个国家的比较。

数据透明单独讲，不计分：纽约 2012 年立法规定政府数据默认公开；上海的公厕明细需要申请，租金统计、露宿人数没有公布，期望寿命停在 2022 年。

## 数据说明和局限

- 数据截至 2026 年 10 月，优先使用两城官方统计；个别更早的数据（如 2020 年人口普查）在文中注明年份。
- 上海用全市常住人口口径；纽约用纽约市（五个区），市级数据缺失时用纽约州或纽约都会区，文中注明。
- 人民币和美元按 1 美元 = 6.733 元换算（2026-10-09 中间价）；两城收入差距按家庭收入约 2.65 倍计算。
- Numbeo、Wise、行业报告等非官方数据只作旁证，不用于判分。
- 社区设施覆盖率是本组用 OpenStreetMap 数据算的：直线距离、已标注居住用地面积口径，不是官方统计，也不是 15 分钟步行可达率。
- 纽约同学访谈只有一位受访者，只作补充，不作统计依据。
- 纪录片《何以为家》的引文按视频转录，不是官方表述，以视频原话为准。
- "我家所在街道"一节不公开具体街道，地图和照片中可识别的名称已做模糊处理；访谈原始记录不公开。
