# 人民城市考卷：上海 vs 纽约

大学 pre，三人组，15 分钟以内（上限 20 分钟）。

## 思路

把"人民城市"当成一张考卷：上海和纽约用同一套分项指标作答，各有失分项。观点以我们自己的身份提出，每个观点都要有数据支持。

- 开场一分钟讲厕所：上海做了什么、纽约做了什么，以及两城公厕"总账"的差别
- 详讲五题：住、行、对待底层、文化、数据透明。每题先讲上海做了什么，再看数据，最后和纽约比
- 计分表一页带过：吃、穿、医疗、治安、教育
- 数据全部用最新官方数据；非官方来源单独标注
- 数据优先：新数据推翻旧结论的，计分表跟着改，讲稿里主动说明
