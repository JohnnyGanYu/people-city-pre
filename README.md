# 人民城市考卷：上海 vs 纽约

大学 pre，三人组，推荐 15 分钟，上限 20 分钟。

## 思路

把"人民城市"当成一张考卷：上海和纽约用同一套分项指标作答，各有失分项。观点以我们自己的身份提出，每个观点都要有数据支持。

- 结构：开场厕所 -> 比较对象与收入 -> 基本项（住、吃、穿、行）-> 加分项（医疗、治安、教育、文化）-> 对待底层 -> 家门口的服务、办事和建设（不计分）-> 计分表与结论 -> 最后讲数据透明（不计分）
- 能找到上海具体做法的题，先讲上海做了什么，再看结果
- 每题分胜负、标程度，不报总比分；结论直接回答"纽约能不能叫人民城市"
- 数据用最新官方数据；非官方来源不进正文，只在备注或答辩卡里说明
- 判分和措辞统一以 `script/口径表.md` 为准
