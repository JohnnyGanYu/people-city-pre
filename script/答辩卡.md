# 答辩卡：台下可能追问的口径问题

正文只留一句话的说明，下面是被追问时的完整回答。数据编号见 `data/data-table.md`。

| 可能的追问 | 回答 |
|---|---|
| 上海公厕 8,325 处包括哪些？ | 这是开放平台"城市设施-公共厕所"数据集的记录条数，由市绿化市容局提供，平台没有写明统计范围，样例里还有已撤销的"闸北区"。纽约 1,064 座只算市政府管理的公厕。所以"三倍"只说明量级（SH-T1、NY-G5、CALC-7） |
| 为什么不用纽约都会区？ | 我们比的是城市政府怎么对待市民，纽约市政府只管五个区。都会区跨三个州，自有住房率等数据也取不全（NY-C6） |
| 收入能直接比吗？ | 纽约是户收入中位数、税前；上海是人均可支配收入乘户均人口，是均值、到手。前者偏高，后者也偏高（均值高于中位数），所以只取"两倍半上下"这个量级（CALC-2） |
| 上海 59% 自有住房率可靠吗？ | 2020 年七普长表，按家庭户统计，不含集体户，所以偏高。纽约 32.3% 是 2023 年住房与空置调查（SH-C1、NY-C5） |
| 为什么不比房租负担？ | 纽约有官方数（租房户房租收入比中位数约 31%），上海统计部门没有公布租金；商业网站和行业报告的数口径不一致，算不出可比的负担 |
| 吃为什么比花销，不比恩格尔系数？ | 比的是吃得好不好，直接看花了多少钱，和穿用同一把尺子。恩格尔系数也指向纽约：上海食品烟酒占消费 25.7%（2024），纽约州在家食品加餐饮住宿占人均个人消费支出 13.5%（2025）；但纽约的分母含雇主和政府代付的医疗等，比住户调查宽，占比偏低，所以只作佐证 |
| 吃的花销口径一样吗？ | 纽约的"餐饮住宿"含住宿，上海的"食品烟酒"含烟酒，两边都偏高一点，不改变量级 |
| 吃和穿为什么用纽约州？ | 纽约市没有单独的消费分项统计，用的是美国商务部经济分析局的州级数据；它的分母含雇主和政府代付的医疗等，比住户调查宽，纽约的比例偏低（3.6 节） |
| 票价为什么按收入折算，不按最低工资？ | 和第 2 节的收入差距保持同一口径。按最低工资折算两城单程大致相当，但纽约最低工资约为上海的 7 倍多，远大于收入差距（CALC-5、CALC-9） |
| 交通支出占比可比吗？ | 纽约都会区 14% 只含交通（2022-23，州审计长引 BLS），上海 10.6% 是交通加通信（2024）。上海多算了一项还更低（NY-D6b、SH-D8） |
| 期望寿命为什么不判分？ | 上海 83.18 岁是 2022 年户籍人口，之后未公布；纽约 83.2 岁是 2024 年全体居民的临时数。年份和人群都不同 |
| 孕产妇死亡率口径一样吗？ | 纽约原始口径算到产后一年（32.2/10 万，2022）；按纽约报告里的死亡时间分布截到 42 天约 21/10 万，与上海口径一致（NY-H11） |
| 杀人案能比吗？ | 上海是公安立案的杀人案，纽约是谋杀案，口径略有不同，但差约 19 倍（SH-H10、NY-H4a） |
| 文化为什么判纽约胜？ | 纽约有三大图书馆系统 200 多个网点、财政资助 1,171 家机构且 96% 有免费或补贴项目；上海只查到市、区两级图书馆 20 个，街镇分馆和免费场馆的全市统一数字没有找到。按能查到的数据判 |
| 上海露宿人数为什么不估？ | 官方没有公布，任何估算都没有出处。判上海胜的依据是纽约自己公布的 12.6 万人和上海的托底制度 |
